Aturan Penting

Dalam setiap commit dan push itu wajib buat selalu di commit jangan sampai lupa karena itu sangat penting buat melihat progres kita, lalu jangan lupa di push karena biar bisa di liat di GitHub . Kalau gak di push nanti gak bisa di cek oleh orang lain progres kita sudah sampai mana

Membangun kebiasaan melakukan commit kecil-kecilan namun rutin, jangan menunggu proyek selesai baru di-commit sekaligus.
